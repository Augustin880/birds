Taxonomy editor

Grow the tree

Add new branches or species under the current taxon. The browse page stays clean while this page handles structure work.

Edit existing entry

Load a branch or species into the form, update its details, then save the changes.

Rank is derived from the selected parent. Images are resolved automatically from img/Aves/Order/Family/Genus/SpeciesEpithet/0.png and the following numbered PNGs in that same folder.

Delete entry

Remove a branch or a species from the taxonomy. Deleting a branch also removes all of its descendants.

Branch images are inherited from the first descendant species folder that contains 0.png, following the current child order.

Storage model

Nodes are normalized by id, child lists are kept alphabetically sorted, and edits are written back to data/taxonomy.json through the PHP endpoint when the app is served by PHP.
